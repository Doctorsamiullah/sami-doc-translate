# 16. ROADMAP.md
## Product Roadmap & Multi-Year Evolution

---

### Phase 1: MVP (Q1) - Foundation & Core Bidirectional Flows
- English ↔ Hindi bidirectional translation on Windows and Android.
- Supported Formats: `.docx`, `.pdf`, `.txt`, `.md`.
- Unlimited-page streaming engine to guarantee zero OOM.
- Basic format converter (PDF ↔ DOCX, TXT ↔ PDF).
- 100% offline local inference via CTranslate2 (Windows) and ML Kit (Android).

---

### Phase 2: Enhanced Format Matrix & Enterprise Features (Q2)
- Expansion to spreadsheets (`.xlsx`) and presentation decks (`.pptx`).
- Advanced batch folder translation with recursive subfolder reconstruction.
- Side-by-side post-editing studio with real-time Devanagari virtual keyboard.
- In-memory SQLite Translation Memory synchronization across user sessions.

---

### Phase 3: Scanned Document OCR & Vision AI (Q3)
- Integration of Tesseract OCR / ML Kit Text Recognition for non-searchable scanned PDFs and image receipts.
- Intelligent dual-layer PDF generation (searchable Devanagari text overlay on original scanned imagery).
- Camera translation scanner mode for Android app.

---

### Phase 4: Multi-Indic Expansion (Q4)
- Generalization from English ↔ Hindi to all 22 scheduled Indian languages (Bengali, Tamil, Telugu, Marathi, Gujarati, Kannada, Malayalam, etc.) using AI4Bharat IndicTrans2 full model weights.
- Multi-lingual document translation packs and localized UI strings.
