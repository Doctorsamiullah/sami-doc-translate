### 3. Minimum Hardware Specifications
- **Windows**: Dual-core CPU (Intel Core i3 / AMD Ryzen 3 or newer), 4 GB RAM (8 GB recommended), 1.5 GB free disk space.
- **Android**: Android 8.0 (Oreo / API 26) or higher, 2 GB RAM, 200 MB free internal storage.
