### 1. DOCX Run-Level Layout Preservation Engine

Microsoft Word documents (`.docx`) store text inside Runs (`w:r`) within Paragraphs (`w:p`). Naive paragraph-level translation strips bold, italic, colors, and font tags.

#### The Algorithm:
1. **Sentence Boundary Detection**: Extract all raw text from a paragraph, detect sentence boundaries using regex or IndicNLP.
2. **Run Span Mapping**: Map sentence start/end character offsets back to the underlying XML run objects (`w:r`).
3. **Protected Entity Masking**: Identify dates, emails, URLs, and code tokens. Replace with protected tags like `<ENT_001>`.
4. **Translation**: Dispatch masked text to NMT engine (`Opus-MT` or `ML Kit`).
5. **Unmasking & Devanagari Font Tagging**:
   - Restore protected entities.
   - Inject translated text into the corresponding run.
   - For Hindi output runs: Explicitly set `rPr/w:rFonts` to `Noto Sans Devanagari` and adjust line pitch to prevent Matra clipping.

### 2. PDF Streaming Engine (Unlimited Pages)

PDFs present fixed coordinate systems rather than fluid XML flows.

```python
import fitz  # PyMuPDF
from typing import Generator

def stream_pdf_pages(file_path: str) -> Generator[fitz.Page, None, None]:
    doc = fitz.open(file_path)
    try:
        for page_index in range(len(doc)):
            page = doc.load_page(page_index)
            yield page
            # Explicit page cleanup to keep memory constant
            del page
    finally:
        doc.close()
```

#### Bounding Box Refitting for Hindi:
Because Hindi translations are typically **15% to 30% wider** than English source sentences, DocTranslate implements **Dynamic Font Scaling**:
- Calculate original bounding box area: \( W \times H \).
- If translated text exceeds original width \( W \), proportionally scale down the font size by factor \( s = \frac{W}{\text{TextLength} \times \text{CharWidth}} \) down to a readable minimum (8pt).
- Re-render text using embedded `Noto Sans Devanagari` font bytes.

### 3. Android Kotlin Document Processing

On Android, SAF provides a `ContentResolver` `InputStream`.

```kotlin
class StreamingDocxTranslator(private val engine: ITranslationEngine) {
    suspend fun processDocument(inputUri: Uri, outputUri: Uri, context: Context, onProgress: (Int, Int) -> Unit) {
        context.contentResolver.openInputStream(inputUri).use { inputStream ->
            context.contentResolver.openOutputStream(outputUri).use { outputStream ->
                val document = XWPFDocument(inputStream)
                val totalParagraphs = document.paragraphs.size
                
                document.paragraphs.forEachIndexed { index, paragraph ->
                    val sourceText = paragraph.text
                    if (sourceText.isNotBlank()) {
                        val translatedText = engine.translate(sourceText, "en", "hi").getOrDefault(sourceText)
                        // Preserve run styles while updating text
                        updateParagraphRuns(paragraph, translatedText)
                    }
                    onProgress(index + 1, totalParagraphs)
                }
                document.write(outputStream)
            }
        }
    }
}
```
