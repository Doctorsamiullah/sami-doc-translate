# 20. CODING-STANDARDS.md
## Coding Conventions, Quality Gates & Architectural Rules

---

### 1. Python Standards (`windows-app/`)
- **Style Guide**: Strict PEP 8 compliance enforced via `flake8` and `black`.
- **Typing**: 100% type annotations on all public functions and class methods (`mypy --strict`).
- **Docstrings**: Google-style docstrings explaining parameter constraints and exceptions.
- **Resource Cleanup**: Always use context managers (`with fitz.open(...) as doc:`) to prevent open file leaks.
- **Thread Safety**: Never perform long-running document translations or model inference on the Qt GUI thread. Always use `QThread` or `QRunnable` with `QThreadPool`.

---

### 2. Kotlin Standards (`android-app/`)
- **Style Guide**: Official Kotlin Style Guide enforced by `ktlint` and `detekt`.
- **Architecture**: Clean Architecture + MVI / MVVM using Android Jetpack ViewModels, StateFlow, and Coroutines.
- **Asynchronous Flow**: Never block the main thread. Always dispatch document parsing and ML Kit calls on `Dispatchers.IO` or `Dispatchers.Default`.
- **Compose Rules**: State hoisting must be maintained. Composables should accept lambdas for event callbacks rather than passing ViewModels directly into leaf components.
- **Storage Safety**: Always wrap `ContentResolver` file operations in `use { ... }` blocks to ensure streams are closed.
