# 24. PERFORMANCE.md
## Performance Benchmarks, Memory Caps & Profiling

---

### 1. Hard Memory Limits (Zero-OOM Guarantee)
To guarantee that documents of unlimited page counts can be processed safely:
- **Windows Desktop Application**:
  - Max resident set size (RSS): **< 600 MB** regardless of whether the document has 10 or 1,000 pages.
  - Streaming window size: 1 page or 25 paragraphs buffered simultaneously.
- **Android Native Application**:
  - Max process memory: **< 250 MB**.
  - Background execution runs in a foreground `WorkManager` worker to prevent OS low-memory termination.

---

### 3. Translation Memory Speedup
Because technical and legal documents have high redundancy (e.g., standard disclaimers, headers, repeated terms):
- **Translation Memory Hit**: Instant (< 0.5 ms per sentence via SHA-256 indexed SQLite lookup).
- **Average Redundancy**: 20% to 35% across multi-chapter technical manuals, yielding a **30% speedup** on repeated sections.
