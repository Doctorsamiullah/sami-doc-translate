## Agent Operating Manual for Claude & Gemini

---

### 1. Project Overview & Boundaries
DocTranslate is composed of two independent applications:
- `windows-app/`: Python 3.11 + PySide6 desktop app.
- `android-app/`: Kotlin + Jetpack Compose Android app.
- Shared documentation resides in `docs/`.

**Golden Rules**:
1. Do NOT mix Python and Android code. The folders are strictly decoupled.
2. English ↔ Hindi bidirectional translation only.
3. Every document parser MUST support unlimited streaming (yield page-by-page).
4. Never remove or bypass Devanagari font substitution (`Noto Sans Devanagari` / `Mangal`).

---

### 2. Common Build & Verification Commands

#### Windows Desktop:
```powershell
cd windows-app
# Run application
python src/main.py

# Run test suite
pytest tests/ -v

# Run formatters
black src/ tests/
flake8 src/ tests/
```

#### Android Native:
```powershell
cd android-app
# Run unit tests
.\gradlew testDebugUnitTest

# Assemble debug APK
.\gradlew assembleDebug

# Check code style
.\gradlew ktlintCheck
```

### 3. File Map & Key Entry Points
- Desktop UI: `windows-app/src/gui/main_window.py`
- Desktop Translation Core: `windows-app/src/core/nmt/ctranslate2_engine.py`
- Desktop Document Parser: `windows-app/src/core/parsers/docx_parser.py`
- Android Main Activity: `android-app/app/src/main/java/com/doctranslate/app/MainActivity.kt`
- Android Translation Engine: `android-app/app/src/main/java/com/doctranslate/app/domain/MLKitTranslator.kt`
- Android Storage Handler: `android-app/app/src/main/java/com/doctranslate/app/data/SAFHelper.kt`
