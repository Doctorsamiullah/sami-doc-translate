# 18. DEPLOYMENT.md
## Build Pipelines, Packaging & Distribution

---

### 1. Windows Desktop App Packaging (`windows-app/`)

#### Step 1: PyInstaller Executable Compilation
The desktop app is bundled using PyInstaller with explicit inclusion of PySide6 binaries, model weights, and Devanagari TTF fonts:

```powershell
# Inside windows-app/
pyinstaller --noconfirm --onedir --windowed `
    --add-data "assets;assets" `
    --add-data "models;models" `
    --icon "assets/icon.ico" `
    --name "DocTranslate" `
    src/main.py
```

#### Step 2: Inno Setup Installer Generation
Inno Setup compiles the PyInstaller output directory into a single installer: `DocTranslate-Setup-v1.0.exe`.
The `.iss` script configures:
- Installation directory: `{autopf}\DocTranslate`
- Desktop shortcut and Start Menu folder.
- Registry keys for Windows Explorer context menu: *"Translate to Hindi with DocTranslate"*.

---

### 2. Android App Packaging (`android-app/`)

#### Step 1: Keystore Signing Configuration
Store the signing keystore credentials securely in `gradle.properties` (or CI environment variables):
```properties
RELEASE_STORE_FILE=../keystores/release.jks
RELEASE_STORE_PASSWORD=********
RELEASE_KEY_ALIAS=doctranslate
RELEASE_KEY_PASSWORD=********
```

#### Step 2: Building Release Artifacts
```powershell
cd android-app
# Build signed production APK
.\gradlew assembleRelease

# Build Google Play App Bundle (AAB)
.\gradlew bundleRelease
```
Artifacts are emitted to `android-app/app/build/outputs/apk/release/app-release.apk`.
