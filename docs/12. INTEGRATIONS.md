# 12. INTEGRATIONS.md
## External Libraries, Open-Source Repositories & Engine Integrations

---

### 1. Translation Backends

#### A. CTranslate2 & Helsinki-NLP (`Helsinki-NLP/opus-mt-en-hi` & `opus-mt-hi-en`)
- **Integration**: Python C-bindings (`pip install ctranslate2 transformers sentencepiece`).
- **Advantage**: 4x faster CPU inference than PyTorch, 8-bit quantization (`int8_float16`), runs seamlessly on standard Windows laptops without dedicated GPUs.
- **Model Size**: ~150 MB per direction.

#### B. AI4Bharat IndicTrans2 (`AI4Bharat/IndicTrans2`)
- **Integration**: Via `IndicTransToolkit` for Indic script normalization, Romanized Devanagari phonetics, and tokenization.
- **Model Checkpoints**: Distilled 200M parameter model for high-fidelity English ↔ Hindi translations.

#### C. Google ML Kit On-Device Translation (`com.google.mlkit:translate`)
- **Integration**: Native Android Gradle dependency (`implementation 'com.google.mlkit:translate:17.0.3'`).
- **Features**: Automatic dynamic language pack downloads (~30 MB per language), zero network footprint during inference, hardware-accelerated via NNAPI.

---

### 2. Audio & Text-to-Speech (TTS)
- **Android**: `android.speech.tts.TextToSpeech` with `Locale("hi", "IN")` for Hindi and `Locale.US` for English.
- **Windows**: Windows SAPI via `pyttsx3` with Hindi voice packs (`Microsoft Hemant` or `Microsoft Kalpana`).

---

### 3. File Parsers & Converters
- **PyMuPDF (`fitz`)**: High-performance C-based PDF parsing, font embedding, and text refitting.
- **python-docx & openpyxl**: Direct OpenXML DOM parsing and streaming.
- **Apache POI (Android port)**: Document manipulation on mobile without native desktop dependencies.
