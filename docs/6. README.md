# DocTranslate: English ↔ Hindi Document Translation & Format Conversion Suite

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Platform: Windows](https://img.shields.io/badge/Platform-Windows%2010%2F11-blue.svg)](https://microsoft.com)
[![Platform: Android](https://img.shields.io/badge/Platform-Android%208.0%2B-green.svg)](https://android.com)
[![Privacy: 100% Offline](https://img.shields.io/badge/Privacy-100%25%20Offline-brightgreen.svg)]()

DocTranslate is a high-performance, privacy-first document translation and format conversion suite. It provides full bidirectional translation strictly between **English and Hindi** with zero layout loss, unlimited page streaming (preventing Out-Of-Memory errors), and an integrated format converter.

---

## 🌟 Key Highlights

- **Strictly Bidirectional**: High-accuracy translation from English → Hindi (Devanagari) and Hindi → English (Latin).
- **Unlimited Pages (Zero-OOM)**: Streaming chunked engine translates 10, 100, or 1,000+ page documents without crashing or exhausting device RAM.
- **Integrated Format Converter**: Convert files between `.docx`, `.pdf`, `.pptx`, `.xlsx`, `.txt`, `.csv`, `.md` — with or without translation.
- **100% Offline & Private**: Powered by CTranslate2 (Opus-MT / IndicTrans2) on Windows and Google ML Kit on Android. No document leaves your device.
- **Two Decoupled Native Apps**:
  - `windows-app/`: Built with Python 3.11 & PySide6 (Windows 10/11 Fluent UI).
  - `android-app/`: Built with Kotlin & Jetpack Compose (Material You).

## 🚀 Quick Start

### Windows Desktop App
```powershell
cd windows-app
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python src/main.py
```

### Android Native App
Open `android-app/` in Android Studio (Giraffe or newer) and click **Run** on your physical device or emulator running Android 8.0+ (API 26+).
