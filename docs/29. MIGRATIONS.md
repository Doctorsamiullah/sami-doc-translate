## Database Schema Migrations & Versioning Strategy

---

### 1. Windows SQLite Migration Strategy
Windows uses simple programmatic migrations tracked via `PRAGMA user_version`:

```python
# windows-app/src/db/migrations.py
MIGRATIONS = {
    1: """
        CREATE TABLE translation_memory (
            source_hash TEXT PRIMARY KEY,
            src_lang TEXT NOT NULL,
            tgt_lang TEXT NOT NULL,
            source_text TEXT NOT NULL,
            translated_text TEXT NOT NULL,
            usage_count INTEGER DEFAULT 1,
            created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
            last_used DATETIME DEFAULT CURRENT_TIMESTAMP
        );
    """,
    2: """
        CREATE TABLE glossary (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            category TEXT DEFAULT 'general',
            term_en TEXT NOT NULL,
            term_hi TEXT NOT NULL,
            case_sensitive INTEGER DEFAULT 0,
            UNIQUE(term_en, term_hi)
        );
    """,
    3: """
        CREATE TABLE job_checkpoints (
            job_id TEXT PRIMARY KEY,
            source_path TEXT NOT NULL,
            target_path TEXT NOT NULL,
            source_format TEXT NOT NULL,
            target_format TEXT NOT NULL,
            total_pages INTEGER NOT NULL,
            completed_pages INTEGER DEFAULT 0,
            status TEXT,
            updated_at DATETIME DEFAULT CURRENT_TIMESTAMP
        );
    """
}

def apply_migrations(conn):
    cursor = conn.cursor()
    cursor.execute("PRAGMA user_version;")
    current_version = cursor.fetchone()[0]
    
    for version in sorted(MIGRATIONS.keys()):
        if version > current_version:
            cursor.executescript(MIGRATIONS[version])
            cursor.execute(f"PRAGMA user_version = {version};")
    conn.commit()
```

### 2. Android Room Migration Strategy
Room handles schema migrations via `Migration` objects:

```kotlin
val MIGRATION_1_2 = object : Migration(1, 2) {
    override fun migrate(db: SupportSQLiteDatabase) {
        db.execSQL("""
            CREATE TABLE IF NOT EXISTS `job_checkpoints` (
                `jobId` TEXT NOT NULL,
                `sourceUri` TEXT NOT NULL,
                `targetUri` TEXT NOT NULL,
                `totalPages` INTEGER NOT NULL,
                `completedPages` INTEGER NOT NULL,
                `status` TEXT NOT NULL,
                `updatedAt` INTEGER NOT NULL,
                PRIMARY KEY(`jobId`)
            )
        """.trimIndent())
    }
}
```
All Room migrations are unit-tested via `androidx.room:room-testing` to ensure no user data is dropped during app updates.
