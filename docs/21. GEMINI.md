### 1. Project Overview & Boundaries
DocTranslate is composed of two independent applications:
- `windows-app/`: Python 3.11 + PySide6 desktop app.
- `android-app/`: Kotlin + Jetpack Compose Android app.
- Shared documentation resides in `docs/`.

**Golden Rules**:
1. Do NOT mix Python and Android code. The folders are strictly decoupled.
2. English ↔ Hindi bidirectional translation only.
3. Every document parser MUST support unlimited streaming (yield page-by-page).
4. Never remove or bypass Devanagari font substitution (`Noto Sans Devanagari` / `Mangal`).

---

### 2. Common Build & Verification Commands

#### Windows Desktop:
```powershell
cd windows-app
python src/main.py
pytest tests/ -v
black src/ tests/
flake8 src/ tests/
```

#### Android Native:
```powershell
cd android-app
.\gradlew testDebugUnitTest
.\gradlew assembleDebug
.\gradlew ktlintCheck
```
