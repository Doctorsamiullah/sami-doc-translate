# 14. DEBUGGING.md
## Troubleshooting, Runbooks & Common Failure Modes

---

### 1. Devanagari Unicode & Font Rendering Issues
* **Symptom**: Hindi text appears as empty rectangular boxes ("tofu" characters like ▯) or broken characters.
  * **Root Cause**: The target document viewer (Word, Adobe Reader) lacks a Devanagari font or the original Latin font (`Calibri`, `Times New Roman`) was not swapped.
  * **Remedy**: Ensure the output pipeline embeds or explicitly sets font attributes to `Noto Sans Devanagari` or `Mangal`. Check `src/core/fonts/font_manager.py`.
* **Symptom**: Misplaced *Matras* (e.g. short-i *chhoti ee* appearing after the consonant instead of before).
  * **Root Cause**: Missing OpenType shaping engine or incorrect Unicode normalization (NFC vs. NFD).
  * **Remedy**: Always pass translated strings through Unicode NFC normalization (`unicodedata.normalize('NFC', text)`).

---

### 2. PDF Bounding Box Overflow
* **Symptom**: Translated Hindi text overflows the page margin or overlaps adjacent paragraphs.
  * **Root Cause**: Hindi text is typically 15–30% longer than English text.
  * **Remedy**: Verify that `fit_text_to_bbox()` in the PDF pipeline dynamically scales the font size down (to a floor of 8pt) and recalculates line wrapping.

---

### 3. Android WorkManager Interruption & Battery Optimizations
* **Symptom**: Translating a 100-page document pauses when the user switches apps or turns off the screen.
  * **Root Cause**: Android Doze Mode / battery optimization suspending the background thread.
  * **Remedy**: Run the translation job inside a **Foreground Service** using `WorkManager`'s `setForegroundAsync()` with an ongoing notification showing live page progress.

---

### 4. Locked File & SQLite Concurrency Errors
* **Symptom**: `sqlite3.OperationalError: database is locked`.
  * **Root Cause**: Concurrent read/write during rapid sentence hashing.
  * **Remedy**: Enable SQLite Write-Ahead Logging (`PRAGMA journal_mode=WAL;`) and configure a 5000ms busy timeout.
