# 9. FEATURE-DEVELOPMENT.md
## Feature Development & Extension Guidelines

---

### 1. Adding a New Document Format
To add support for a new format (e.g., OpenDocument `.odt`, Rich Text Format `.rtf`, or LaTeX `.tex`):

1. **Implement `IDocumentStream`**:
   - Create `src/core/parsers/<format>_parser.py` (Windows) and appropriate parser class in Android.
   - Implement `stream_pages()` or `stream_blocks()` to yield runs with formatting metadata.
2. **Implement `IDocumentWriter`**:
   - Write the translated blocks back to disk while substituting Devanagari fonts (`Noto Sans Devanagari`).
3. **Register Extension**:
   - Update `SUPPORTED_EXTENSIONS` set in `constants.py` and file picker filters in PySide6 / Android SAF.
4. **Update Format Converter Matrix**:
   - Add conversion mappings to `IFormatConverter`.

---

### 2. Adding an Alternative NMT Engine
DocTranslate is engine-agnostic:
1. Implement `ITranslationEngine` (e.g. `IndicTrans2Engine`, `NLLB200Engine`, or local `OllamaEngine`).
2. Add the engine option into Settings dropdown.
3. Verify zero-OOM execution and thread safety when handling concurrent sentence batches.

---

### 3. Adding OCR Scanned PDF Support (Phase 2 Extension)
- Integrate Tesseract OCR (`pytesseract` on Windows, ML Kit Text Recognition on Android).
- Detect scanned pages with zero text layers.
- Perform OCR -> Bounding box extraction -> Translation -> PDF overlay layer creation.
