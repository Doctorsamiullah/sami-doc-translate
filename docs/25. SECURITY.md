# 25. SECURITY.md
## Security Policy, Vulnerability Reporting & Local Sandboxing

---

### 1. Security Architecture
DocTranslate is engineered with privacy and local execution at its core:
1. **Network Disconnection Immunity**: The application executes with 100% functionality when disconnected from Wi-Fi and Ethernet.
2. **Local Sandboxing**: Temporary scratch files generated during page streaming are created under OS-managed temporary folders (`%TEMP%\DocTranslate` and `context.cacheDir`) with restricted file permissions (`0700`).
3. **No Dynamic Code Execution**: The app does not evaluate dynamic scripts, macros, or embedded JavaScript inside PDF or Office documents. All macros (`.docm`, `.xlsm`) have their script payloads stripped during ingestion.

---

### 2. Dependency Audit & Scanning Protocol
- Dependencies in `windows-app/requirements.txt` are monitored via `pip-audit` and GitHub Dependabot.
- Android dependencies are audited via OWASP Dependency-Check Gradle plugin.
- Any dependency with a CVSS score ≥ 7.0 must be remediated or patched within 7 business days.

---

### 3. Vulnerability Reporting
Please report security concerns to `security@doctranslate.internal` or open a private advisory on GitHub. Do not submit public issues for security vulnerabilities.
