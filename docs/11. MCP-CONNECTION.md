# 11. MCP-CONNECTION.md
## Model Context Protocol (MCP) Server Specifications

---

### 1. Purpose & Integration
DocTranslate includes an optional lightweight Model Context Protocol (MCP) server running via standard I/O (stdio). This allows AI agents (such as Antigravity, Claude Desktop, Cursor, or Gemini) to programmatically invoke document translation, format conversion, and glossary lookup.

---

### 2. Available MCP Tools

#### Tool 1: `translate_document`
- **Description**: Translates a document between English and Hindi while preserving layout.
- **Parameters**:
  - `source_path` (string, required): Absolute path to source document.
  - `target_path` (string, optional): Destination file path.
  - `source_language` (enum: `en`, `hi`, required): Source language.
  - `target_language` (enum: `en`, `hi`, required): Target language.
  - `target_format` (string, optional): Target format for conversion (e.g., `pdf`, `docx`).

#### Tool 2: `convert_format`
- **Description**: Converts a document from one format to another without translating.
- **Parameters**:
  - `input_path` (string, required): Source file path.
  - `output_format` (string, required): Desired format (e.g. `docx`, `pdf`, `txt`, `csv`).

#### Tool 3: `query_glossary`
- **Description**: Looks up approved technical, legal, or medical Hindi/English terms in Translation Memory.
