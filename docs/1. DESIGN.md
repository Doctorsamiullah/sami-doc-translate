## User Interface, Interaction Design & Typography Specifications

---

### 1. Design System & Theme Foundations
DocTranslate adheres to native OS guidelines while maintaining brand consistency:
- **Windows Desktop App**: Follows Windows 11 Fluent Design principles (Mica/Acrylic material feel, rounded corners, Segoe UI Variable for Latin, Noto Sans Devanagari for Hindi).
- **Android App**: Follows Material Design 3 (M3) with Dynamic Color (Material You) and Noto Sans Devanagari font integration.

#### Color Palette:
- **Base Canvas**: Crisp Pure White `#FFFFFF` and Eggshell Light `#F8F9FA`
- **Surface Cards**: `#FFFFFF` with 1px border `#E0E0E0` and subtle elevation shadows.
- **Rainbow Light Theme Options**:
  1. 🌈 **Vibrant Rainbow Light**:
     - Spectral Gradient: Violet (`#8E24AA`) → Indigo (`#3949AB`) → Blue (`#1E88E5`) → Green (`#43A047`) → Yellow (`#FDD835`) → Orange (`#FB8C00`) → Red (`#E53935`)
     - Used on active tab indicators, app header gradient trims, and progress bars.
  2. 🎨 **Pastel Rainbow Light**:
     - Soft candy spectrum: Lavender (`#D1C4E9`) → Sky (`#BBDEFB`) → Mint (`#C8E6C9`) → Lemon (`#FFF9C4`) → Peach (`#FFE0B2`) → Rose (`#FFCDD2`)
  3. ⚡ **Prism Spectrum Light**:
     - Glassmorphism light cards with vivid holographic rainbow border outlines and crisp dark text (`#1C1B1F`).
  4. 🌅 **Sunrise Spectrum Light**:
     - Warm sunrise radiance: Amber (`#FFA000`) → Tangerine (`#F57C00`) → Coral (`#E64A19`) → Rose (`#C2185B`) → Violet (`#7B1FA2`).

### 2. Devanagari Typography & Layout Rules
Devanagari text in Hindi presents specific typographic challenges:
1. **Vertical Space & Line Height**: Hindi text requires at least **1.35x to 1.5x line height** compared to English text (1.2x) because upper vowel markers (*Matras* like *e, ai, o, au, anusvara*) and lower markers (*u, oo, ri*) extend beyond standard Latin ascenders and descenders.
2. **Font Substitution Matrix**:
   - Primary: `Noto Sans Devanagari` (Regular, Medium, Bold)
   - Secondary / System Fallback (Windows): `Mangal`, `Aparajita`, `Nirmala UI`
   - Android Fallback: System Roboto + NotoSansDevanagari
3. **No-Break Boundaries**: Compound words (*Samyukt Vyanjan*) must never be broken across lines mid-word.

### 4. Android App Navigation & Layout (Jetpack Compose)

#### Navigation Structure (M3 NavigationBar):
1. **Translate Tab**: File selection, bidirectional language switcher, output format picker, live page translation card.
2. **Convert Tab**: Standalone document format converter (DOCX, PDF, TXT, CSV).
3. **History Tab**: Paginated list of completed jobs, preview, TTS playback button, and Share Sheet trigger.
4. **Settings Tab**: Language pack manager (download/delete English & Hindi packs), Dark Mode toggle, storage cleanup.
