# 8. SETUP.md
## Developer Environment & Toolchain Setup Guide

---

### 1. Prerequisites
- **Operating System**: Windows 10/11 (64-bit).
- **Python**: Version 3.11.x (Add to PATH during installation).
- **JDK**: Eclipse Temurin or Oracle OpenJDK 17.
- **Android Studio**: Android Studio Giraffe | Hedgehog | Iguana or newer.
- **Git**: For version control.
- **Inno Setup**: Version 6.x (for building the Windows installer `.exe`).

---

### 2. Windows Desktop App Setup (`windows-app/`)

1. **Navigate to the folder**:
   ```powershell
   cd "C:\DocTranslate\windows-app"
   ```
2. **Create and activate a virtual environment**:
   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```
3. **Upgrade pip and install dependencies**:
   ```powershell
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   ```
4. **Download offline translation models**:
   ```powershell
   python src/utils/model_downloader.py --model opus-mt-en-hi
   python src/utils/model_downloader.py --model opus-mt-hi-en
   ```
5. **Run the application**:
   ```powershell
   python src/main.py
   ```

---

### 3. Android Native App Setup (`android-app/`)

1. **Launch Android Studio** and select **Open**, then choose the `android-app` directory.
2. **Gradle Sync**: Let Android Studio download required Gradle wrappers, Android SDK platforms (API 34), and dependencies.
3. **Hardware Acceleration**: Enable VT-x / AMD-V in BIOS for the Android Emulator, or connect a physical Android device with **USB Debugging** enabled.
4. **Run**: Select `app` run configuration and click **Run (Shift + F10)**.
5. **Initial Language Pack Download**: On first launch in the app, tap **Settings → Download Offline Packs** to pull the ~30 MB English and Hindi ML Kit translation models over Wi-Fi.
