# 28. UI-COMPONENTS.md
## Component Library & Design Tokens (PySide6 & Jetpack Compose)

---

### 1. PySide6 Desktop Widgets (`windows-app/src/gui/components/`)

- **`LanguageSwapButton`**: A toggle widget displaying `[ English ] <⇄> [ Hindi ]` with smooth icon rotation animation when clicked. Emits `directionChanged(src, tgt)`.
- **`DropZoneWidget`**: Drag-and-drop file target displaying accepted extensions (`.docx`, `.pdf`, `.txt`, `.pptx`, `.xlsx`, `.md`). Highlights on hover and extracts file metadata.
- **`StreamingProgressBar`**: Smooth dual-indicator bar displaying:
  - Total progress percentage (0–100%).
  - Text label: *"Translating page 42 of 180 (ETA: 35s) | Memory: 142 MB"*.
  - Inline `Pause`, `Resume`, and `Cancel` controls.
- **`SideBySidePreview`**: Dual `QTextEdit` split-view with synchronized scrolling and run highlighting (English source paragraph highlighted alongside Hindi translated paragraph).
- **`FormatSelectorPillGroup`**: Radio button group for selecting output format: `[ Same as Source ]`, `[ PDF ]`, `[ DOCX ]`, `[ TXT ]`.
- **`CompressorControlPanel`**: Target size input widget (spinbox with MB/KB units or slider percentage), readability lock switches, and auto-cleanup indicator.
- **`RainbowGradientProgressBar`**: Custom `QProgressBar` styled with a vibrant or pastel animated rainbow gradient fill across the progress track.
- **`RainbowThemeManager`**: Stylesheet switcher applying dynamic QSS templates for the 4 light rainbow themes.

---

### 2. Jetpack Compose UI Composables (`android-app/app/.../presentation/components/`)

- **`RainbowHeader`**: TopAppBar featuring an accent rainbow gradient brush line under the elevation shadow.
- **`CompressorCard`**: Interactive card with target size TextField, slider, readability protection badge, and scratch clear callback.
- **`LanguageToggleCard`**: Material 3 elevated card holding source and target language chips with an animated bidirectional swap icon button (`IconButton`).
- **`FilePickerCard`**: Dotted outline card with system file picker launcher (`rememberLauncherForActivityResult`). Shows selected document icon, file size, and page count.
- **`LivePageProgressCard`**: Card showing linear progress indicator, page count badge, estimated time remaining, and "Safe Streaming Active" shield badge.
- **`HistoryItemCard`**: Material 3 card displaying document title, date, source/target languages, `IconButton` for TTS playback (`Icons.Default.VolumeUp`), and `Share` action.
- **`DevanagariText`**: Text wrapper applying `NotoSansDevanagari` font family, appropriate line-height multiplier (1.4x), and overflow ellipsis.
