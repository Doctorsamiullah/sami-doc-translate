# 17. CHANGELOG.md
## Release History & Version Tracking

All notable changes to the DocTranslate suite are documented in this file.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

---

### [1.0.0] - 2026-10-30
#### Added
- **Core Platform**: Complete specification and architecture for standalone Windows desktop and Android native apps.
- **Bidirectional NMT**: English → Hindi and Hindi → English offline neural translation pipelines.
- **Streaming Engine**: Unlimited-page chunked processing preventing OOM memory spikes.
- **Layout Preservation**: Run-level XML parser for DOCX and bounding-box refitting engine for PDF.
- **Format Converter Suite**: Standalone and inline converter supporting PDF, DOCX, TXT, PPTX, XLSX, and CSV.
- **Offline ML Kit Integration**: Native Android ML Kit on-device translation with offline language pack management.
- **CTranslate2 Desktop Engine**: Fast quantized CPU inference using Helsinki-NLP Opus-MT models.
- **Documentation Suite**: Exhaustive 31-document specification suite covering PRD, Design, Architecture, Database, and QA.

---

### [0.1.0] - 2026-10-15
#### Added
- Initial project concept, research benchmarks on IndicTrans2 and Helsinki Opus-MT models.
- Preliminary CLI prototypes for DOCX run extraction.
