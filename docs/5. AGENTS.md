# 5. AGENTS.md
## Autonomous Agent Operational Directives & Guidelines

---

### 1. Operational Scope for AI Agents
Any AI agent (Antigravity, Claude Code, Gemini CLI, Cursor, etc.) working on this repository must strictly adhere to the following rules:

1. **Folder Boundary Isolation**:
   - `windows-app/` must NEVER import, reference, or share code with `android-app/`.
   - `android-app/` must NEVER rely on Python scripts or Windows desktop binaries.
   - Any shared business logic must be represented in `docs/` and implemented idiomatically in each respective language (Python for Windows, Kotlin for Android).
2. **Offline-First Guarantee**:
   - NEVER inject network telemetry or cloud API calls into default flows.
   - All tests must pass in completely offline mode (simulated airplane mode).
3. **Memory Bounding on Multi-Page Documents**:
   - Never implement `read_all_pages()` or load entire documents into a single in-memory buffer.
   - Always verify that document processing uses streaming generators, chunked iterators, and explicitly closed file descriptors.
4. **Devanagari Typography Preservation**:
   - Every font injection step for Hindi output must verify fallback to `Noto Sans Devanagari` or `Mangal`.
   - Never strip Unicode combining characters (*halants, matras, nuktas*).

### 2. Common Agent Commands

#### For Windows App (`windows-app/`):
```powershell
# Setup virtual environment
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt

# Run Desktop UI
python src/main.py

# Run Test Suite
pytest tests/ -v
```

#### For Android App (`android-app/`):
```powershell
# Gradle build & test
cd android-app
.\gradlew.bat testDebugUnitTest
.\gradlew.bat assembleDebug
```
